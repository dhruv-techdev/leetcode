## Structure

Each problem lives in its own folder under the matching category.

```
leetcode/
└── <category>/
    └── <number>_<problem_name>/
        └── solution.py
```

<br>

**Example**

```
strings/3_longest_substring_without_repeating_characters/solution.py
```

## Usage

```bash
cd <category>/<number>_<problem_name>
python solution.py
```
